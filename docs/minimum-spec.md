# Minimum spec

Generated by `node scripts/min-spec.mjs` from the reports in `docs/perf-reports/`; do not edit by hand. Design: `handover/design/SSE4-performance-and-minimum-spec.md`.

A report comes from the chart room (More › Performance readout › Copy report or Save) or from the bench on `/harness/` (Run the bench › Copy report or Save), or from `node tests/harness/bench.mjs --out <dir>`. Save it in `docs/perf-reports/` under a short name and run the script.
