# Paper spacecraft (store pack, track RK, package RK6)

Engines and ships that were designed in detail and never built, each from its own study, flying on SSE4's own physics and marked "not yet built". Published on Explorers and **not** built into SSE4: nothing under `store-packs/` is loaded by the kernel or the app.

- `pack.json` is generated by `python3 -I scripts/build-paper-spacecraft.py` (`--check` says whether it is up to date). Do not edit it by hand.
- What it carries (all under `provides.other`):
  - `engines`: sse-nav engine designs by id (RK9's shape), with `engine_notes` saying where each figure comes from and how any was worked out.
  - `nav_ships.ships`: ship records with fitted engines, so the power books set the drive; `recipes` says what each study claimed (`study_says`) and which advances it leans on.
  - `tech.advances`: drives and plants that join base-tech's, all `not yet built`.
  - `waiting`: studies SSE4 cannot fly yet (the Starshot sail waits on RK5's beamed legs).
  - `tours`: three tours as data (`sse.tour/1`, stops are `sse.bookmark/1`); they play once tours and bookmarks are built (playbook design PB2b).
- Checks: `crates/sse-kernel/tests/paper_spacecraft.rs`.
- Sources, quotes and pages: `handover/packages/RK6-data/RK6-sources.md`. The Atomic Rockets site was used only as a map to primary sources; its name, text, tables and selection are not used (plan section 7, package RK8 waits on its author's written reply).
