# MATCH1 reference pictures

Reference pictures for the renderer comparison: famous NASA and ESA images against SSE4's own postcards, made at the
same pose (renderer thread, package note handover/packages/MATCH1.md in the repo).

The handoff with the trailer thread works like this:
- Each folder holds `ref.jpg` (the picture), `credit.txt` (its title, credit, date, source, licence, and why it was
  picked) and `pose.json` (the place, date, camera, band and view to match it, and what SSE4 still needs).
- The trailer thread films the pose on Alex's PC and makes the side-by-side still. It never retouches SSE4's side, and
  it checks the licence before anything is published.
- These pictures stay in project files and are never committed to the repo.

Licences:
- NASA images are generally not subject to copyright in the US. Credit NASA (and the named centre or team) and don't
  imply endorsement: https://www.nasa.gov/nasa-brand-center/images-and-media/
- ESA/Hubble and ESA/Webb images are CC BY 4.0, with the credit line exactly as given: https://esahubble.org/copyright/
- Juno's processed images often credit a citizen scientist, so check the source page first.
