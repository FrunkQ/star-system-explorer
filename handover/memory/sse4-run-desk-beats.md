Alex, 24 Nov 15:28, answering the run sheet question: "a gm must always be able to adapt and remix - having a series of presets to jump to... show planet x detail, landing sequence on planet y, etc. are great to have 'in hand' but live is the key."

Built by thread "Build Run desk and players' side" as a **hand of beats**:
1. Every live step (fly, reveal, send this view, land, screens off) always a press away on the Run desk.
2. Beats are presets prepared beforehand, played in any order with one press; Next optional, never required.
3. Anything done live can be kept as a beat with one press; beats editable, reorderable, skippable mid-session.
4. Players see only what a beat sends, same as a live press.

**How to apply:** never make the Run desk a fixed script or gate live actions behind the sheet. Related: [[sse4-coming-together]].
