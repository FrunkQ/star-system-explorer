# Old project memory (copied 24 Nov 2026)

A full copy of the SSE4 project memory from Alex's first Claude account, taken on 24 Nov 2026 before the move to a
new account. `MEMORY.md` is the index (it was loaded into every session); each other file is one subject with
frontmatter (`name`, `description`, `type`). `[[name]]` links point at other files here by their `name`.

These are dated notes, not live state. Where a note names a file, PR, function or flag, check it against `main`
before relying on it. The newer source of truth for track state is `handover/status/`.

A new account can load these into its own project memory, or simply read them from here.
