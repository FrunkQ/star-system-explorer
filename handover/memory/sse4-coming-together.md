`/mnt/project-files/sse4/SSE4-coming-together.md` (repo copy `handover/design/`, PR 195) is the short plan for joining SSE4's tracks up. Written 22 Nov 2026 by the thread "Plan how SSE4 comes together". **Status: accepted. Alex said "yes to all" on its seven questions on 23 Nov 2026.**

Stages (order the joining up, not what threads may build underneath):
1. Test drive: one walk (start, system, world, time, galaxy and back via the place line, Reference), added to the shell check, plus `handover/test-drive.md` rough-edges list.
2. One system told in full: formation story screen (reading half first), Reference finished, field history, cutaway ice zones, Life on chart worlds.
3. One language underneath: Equation block (ND3, ND3b), typed copies to zero (MP22), light through gas (ND2), editor adds and wires nodes.
4. The galaxy has a past: DM and GH, night sky.
5. Run a game: Traveller screens, programs part 2, tags, Explorers V4 packs.
6. Show it: Orac paper demo, True views, tours, films. Then 4.1 economy.

Cross-cutting lanes (accepted): MP22 sweeps a crate before ND3b moves that crate's atoms; ND2 starts after ND3; one golden-changing PR open at a time; package status lives in `handover/status/<track>.md`, one file per track edited only by its owner thread, with START-HERE.md as index only (PR 216). Questions reach Alex as one numbered list a day through the coordinator.

**Why:** Alex, 22 Nov: "there is a natural order to this - we dont need it fully working at each stage... but we need to have a broad plan on how to bring it all together without overwhelming or getting messy."
Joining-up principle (Alex, 23 Nov): "stitch everything together so it feels intuitive and approachable. Most common things a click away. Rarely touched things in menus that have relevant context." My reading, written into the plan: common actions sit on the thing itself; rare ones in that thing's own menu, never a global list; each stage's walk records clicks per step.
**How to apply:** place new screens and asks by stage; follow the lanes before any sweep or golden change; apply the click-away test to every screen being joined up.
