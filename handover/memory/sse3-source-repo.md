SSE3 (V3) source is the public repo FrunkQ/star-system-generator (any session can read it via `git clone --depth 1`, no attach needed).

- Guide jokes: `src/lib/catalogue/guideNotes.ts`, 131 lines (Alex's Mostly_harmless.txt). 36 use Douglas Adams names or phrases and go to a separate unofficial fan pack; the rest are the base Guide's (atlas design 6.6, 14A).
- Starter logos: `static/images/logo/`. Interspan, Kelido, Nexum, Terra, TSEC are by World Zero (worldzero.itch.io), CC BY 4.0, credited in SSE3's AboutModal.svelte. SSE.png is Alex's own. Weyland-Yutani.png is excluded unless Alex says otherwise in his own words.

Used by track AT (AT6 logos, AT7 margin notes). See [[sse4-atlas-and-editions]].
