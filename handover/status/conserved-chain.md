# Status: the conserved budget chain (track CC)

Owner thread: "Design the conserved budget chain" (Fable, design only, 26 Nov 2026) for the note, the check set (CC2) and the split specs (CC5). No builder thread yet. Until one exists, each package below belongs to the thread named in its row, and that thread records it in its own status file too.
Design: `design/SSE4-conserved-chain-design.md`, **ACCEPTED by Alex 26 Nov 2026 14:52 UTC** ("Yes to all - make sense"). Read its sections 1, 2, 10, 11 and 13 first; his rulings (sections 1, 10, 11) win where they differ. The audit it answers: https://claude.ai/artifact/Mh4vmc9CB4c36j5pSThCbn.

What it is, in one line: one mechanism at every level (a reservoir by category through time, a split set by the seed, stubs that cost nothing, flows with two ends), so that mass and the six element groups are carried from the web to a named crater, looking never changes the universe, and only deeds (GM edits and play) do.

**Standing rule from here (build plan section 1):** no join between levels passes a description without an amount, and every join has three tests: closure, indifference to the order and date of looking, and no stand-in place. Each new test is first run against the code without the fix and seen to fail.

**Working rule on accuracy (Alex, 26 Nov):** plausible, repeatable and explained, not exact. Exact books only where already built or nearly free. "Nothing we have now is important": alpha universes may be blown away; there is no legacy to protect.

Nothing is built. CC is a code only, never shown in the product.

**Hold until CC6 lands** (the star field changes once): the Local stars rung (GZ7), the gazetteer's star rows (GZ17), and any golden or stored picture fixed to particular generated stars. Safe to carry on: GZ12, GZ13, GZ15, the Local Group view, everything inside a system, surfaces, weather, light, the renderer, editing, the desks.
