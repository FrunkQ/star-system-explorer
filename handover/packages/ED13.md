# ED13: the sheet, "Type it all in" (editing design section 3, "The sheet"; 10B F1)

## Part 1 (25 Nov): one body's sheet

- `packages/ui-contract/src/sheet-entry.ts`:
  - `sheetRows(handles, depth)`: each handle in row order, then its box parts (strips and rings), as rows. The makeup
    bar waits for its box, and the place round the orbit now (`as: true_anomaly_now`) is left to the box because it is
    read off the date.
  - `spreadPaste(rows, text, start)`: a line whose first cell names a row (either depth's name, the field or the id)
    goes to that row, last cell as the value. Any other line takes the next row down from where the paste landed. Cells
    split on tabs, semicolons or two or more spaces.
  - `readSheet(rows, typed, facts, cls, depth)`: each figure is read by `readFigure` in any unit of its kind. A bare
    number on a fraction-said share (Shape 0.05) is that fraction. It returns the edits (an unchanged value writes
    nothing), what it understood in the body's own units, and the problems. Test: `test/sheet-entry.test.ts`.
- `commitFields` (edit.ts) takes `evidence` and `source`: catalogued figures go in as the kernel's catalogued evidence
  with their source, as the start sheet's Sol does.
- `packages/views/editing/src/Sheet.svelte`, opened by "Every input · Type it all in" at the end of the handles row
  (GM, Build or a what-if). It writes through `Handles.commitMix` (label "Typed in"), so "What followed" works as for
  any handle.
- e2e (`editing.e2e.mjs`, desk): Mars, mass to 0.2 Earth masses and shape 0.05, "banana" for Spin shown as not read;
  marked catalogued from "A paper's table"; one change, then one Undo. Screen: project files
  `sse4/handover-screens/ED13-screens/sheet-desk.png`.

## ED13a part 1 (25 Nov): the system sheet

- `readTable(text, rowsFor, bodies, depth)` in `sheet-entry.ts`: the first line names the columns. Each column is
  matched to an input by either depth's name, its field or its id, and a unit in brackets ("Orbit (AU)") is the unit
  of that column's bare numbers. The first column names the body (by its chart name). Cells split on tabs, semicolons,
  commas or two or more spaces; "-" or an empty cell is left alone. Columns naming no input and bodies not in this
  system are listed and left out.
- `commitFields` takes an `address` per edit. The undo record is keyed `"<address>#<field>"`, so one Undo puts every
  body back.
- `Sheet.svelte` has "This body" and "Every body here" (shown when the system has more than one body). `Handles`
  hands it `sheetBodies` (every world and star here, with the kernel's facts) and `rowsFor`.
- e2e: a table setting Mars's orbit (1.6, from "Orbit (AU)") and Earth's mass, with "Vulcan" said as not here; one
  change, then one Undo. Screen: `ED13-screens/system-sheet-desk.png`.

## ED13a part 2a (25 Nov): a file

- "Every body here" has "Open a file" (`data-sheet-file`, .csv, .tsv, .txt) and takes a file dropped on the box. The
  file's text goes into the box, so it is read and checked exactly as a paste is; nothing is set until "Set". Over 2 MB,
  or a file that is not text (a spreadsheet's own .xlsx), is refused with "save the sheet as CSV first".
- `readTable` reads a spreadsheet's saved CSV: a byte-order mark, quoted cells (a comma or doubled quote inside), and
  grouped thousands ("642,000,…") taking the bracketed unit. Unit test in `sheet-entry.test.ts`; e2e opens worlds.csv.
- Screen: project files `sse4/handover-screens/ED13-screens/sheet-file-desk.png`.
