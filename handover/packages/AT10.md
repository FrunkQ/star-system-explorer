# AT10: the GM's own copy (atlas design section 5, last paragraph)

## What it is

- **Seen by the GM, nothing is barred.** What the table has not been told is drawn in **pencil**: a dotted underline
  and the muted ink, as on the chart (SV2). It prints the same way, in both ink settings.
- The page says what pencil means once: "In pencil: what the table has not been told."
- When the table does not know the place at all, the title is in pencil and the line reads "In pencil: the table does
  not know this place yet."
- **The same bytes, nothing guessed.** A line is in pencil exactly when the table's own page would show a gap there.
  The test is `tableKnows`: the table's scene from the kernel `scene` op with audience `everyone`, read beside the
  GM's.
- Table cells pencil the same way. A table block now carries `fields`, the fact field of each column.
- **GM notes** print in their own section on the GM's copy. These are the place's live `gm-notes` note from the record
  (`session.record`, `placeNoteOf`), the same notes as the place line's Notes panel. Blank notes are dropped.
- **Never on anyone else's copy.** `withGmCopy` returns any page that is not the GM's unchanged.
- **Text, Markdown and HTML** mark a pencilled line with " (pencil)" (`PENCIL_TEXT`). Pencilled HTML gets a `pencil`
  class, and GM notes print under GM NOTES.
- **Pure:** `ui-contract/src/atlas/gmcopy.ts`. The view reads the table's scene and the GM notes for the page in front.
  "Print…" reads the GM notes for every page first.
