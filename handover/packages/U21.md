# U21: The start sheet, part 1 (UI track)

Status: part 1 done 22 Nov 2026. Top-level design step 3 (sections 3.1, 3.4 and 16). The app now opens on one chart-room sheet instead of straight on the Kestrel fixture. Part 2 adds the Solar System as the first place.

## What it does

- **Opening line.** It changes by itself and has no control (section 16.1). The first visits show the expected lines in order (1, 3; line 2 waits for the Solar System). After that it is a weighted pick: never the same line twice running, and a line about something this person has not opened is twice as likely. While the sheet is open, the line fades to the next about every 12 s. It holds still under the pointer or focus, and with reduced motion it changes per visit only. "Show me ›" opens what the line names. The 42 lines from section 16.3 live in `packages/shell/src/documents/start.lines.json` (id, headline, sentence, opens, weight, needs, audience). A line whose `needs` are not built is held back. Held back now: the Solar System lines (2, 22, 28, 33, needing `sol`), Traveller import, programs, examples, Find, class atlas, Explorers shelf, converter, survey from afar, spectrum, tours.
- **Begin.** Three doors:
  - "Carry on: <campaign>, kept <when>" when this browser keeps a campaign, else "Open the sample campaign" (Kestrel Reach).
  - "Grow a new system" opens Make on its grow tab (`MakeSystem` gains a `start` prop).
  - "Open or bring a campaign" opens the Campaign dialog, which gains "A save from Star System Explorer 3? Bring it in with Make a system ›".
- **What it can do.** Ten verbs, each opening the real thing until tours exist (step 5): Cut a world open (Cutaway), Take a photograph (Globe), See in other light (opens the Light control), Follow life, Plan a trip (Route), Look out of the window, Zoom all the way out, Ask why (Tars), Run a game (Run desk). World instruments open on the selected world, else the first planet. "Age the Sun" is held back until the Solar System is in (part 2). The list is `atlas` in the same document.
- **Reassurance line**, "Open straight to the chart next time" (remembered on this device), and "Go to the chart ›".
- **Leaving and coming back.** Escape leaves the sheet. More › Start sheet brings it back. The sheet takes no chart keys. The app behind it is `inert` while the sheet is up. It is not modal (rule 3.4.6), so leaving loses nothing.
- **`#chart`** at the end of the address opens straight to the chart. Every GM browser test now loads `base + "#chart"`. The trailer capture script defaults a shot's path to `#chart` for the same reason, and a shot can still film the sheet by setting `path: ""`.
- **Per-device memory only** (prefs `sse4.start*`): visits, the last line, what was opened, and skip. Nothing is sent anywhere.
- `packages/ui-contract/src/start.ts`: `pickLine`, `shownLines`, `opensKey`, `checkStartLines`.

## Part 2 (next)

- **"Open the Solar System"** (marked "start here") as the first door. SSE4's own Sol is entered as one batch of cited, catalogued facts (NASA Planetary Fact Sheet, IAU nominal values): the Sun, the eight planets, the Moon, the main belt, the Kuiper belt and a spherical Oort cloud. It waits on the kernel's `set_authored_batch` with `evidence: "catalogued"` (PR 134, kernel thread). The `sol` lines and Age the Sun then show. V3's Sol is a reference only.
- Tours (step 5) replace "opens the real thing" with a two-minute tour on the real desk.

## Checks

- `packages/ui-contract/test/start.test.ts` checks:
  - the shipped document is well formed: 42 lines, three first, ten verbs;
  - held-back lines stay hidden until their feature is built;
  - the first visits run in order and skip held-back lines;
  - 400 later picks never repeat and cover every shown line;
  - opened things thin out.
- `tests/ui/start.e2e.mjs` (desk and phone) checks:
  - a fresh browser opens on the sheet with line 1;
  - all four doors are present, and nine verbs (Age the Sun held back);
  - there is no overflow on a phone;
  - Escape leaves the sheet, and More › Start sheet brings it back with line 3;
  - Cut a world open lands on the Cutaway;
  - Grow opens Make on its grow tab;
  - skip is remembered across a reload;
  - `#chart` skips the sheet on a fresh device;
  - there are no page errors.
