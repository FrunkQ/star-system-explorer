# X3a part 1: code sheets and Traveller world codes from classification rules

Status: done (19 Nov 2026), Traveller pack track, PR into `main`. Design: handoff 7A part 1; build plan X3a (codes from rules only; every digit answers why; world to UWP to world keeps every digit). Part 2 (units, calendar, vocabulary, lenses, reports, sifters, and a kernel op for the UI) follows.

## What was built
**Crate `sse-codes` (general, no game in it).** A *code sheet* is pack data (`provides.other.code_sheets`):
- `segments`, each one symbol, read by existing machinery:
  - `classify`: a region-scored scheme (K8/C1) whose classes each map to a symbol and a value; the why is the atlas's own `Label` (facts read, near misses with the change needed) plus `defaulted`, the facts that were absent and stood in by the axis's `missing` value;
  - `leading`: leading digit of a fact at the power of ten another segment settled (population multiplier), whole-number arithmetic only;
  - `count`: bodies in the same system carrying a rule tag (belts, gas giants), with the members listed.
- `authored`: a fact holding the symbol itself. Present, the code wins, and the reading keeps what physics would give beside it (`SegmentReading::disagrees`), which is what X3b marks as impossible.
- `prepare`: K8 rules run first; each rule's tag becomes a flag fact the classes read (e.g. "air carries oxygen").
- `groups`: after the segments, each value is published as `<fact_prefix><segment>` and every rule whose tag starts with the group's prefix runs: trade codes, zones, bases. Their evidence is the digits; the digits' evidence is their labels.
- `layouts`: templates such as `{starport}{size}...-{tech}`.
- The way back: `parse`, `pins` (each symbol's class cores as ranges in fact units, typical values, several classes per symbol allowed), `typical_world` (the plainest world for a code line; X3b's constrained resolve starts from the pins).
- `Codes::load(stack)` checks every sheet: schemes exist, every class of a segment's scheme has exactly one one-character symbol, layouts use known segments, count tags have rules.

**Pack `packs/traveller/pack.json`** (`sse.traveller`, kind game-system), generated by `scripts/build-traveller-pack.py` (edit the script):
- Eight region schemes, 140 classes: starport (authored `society.starport`), size (diameter in 1600 km steps from `body.radius`; belts as size 0), atmosphere (pressure bands × oxygen, taint and corrosion flags; E and F authored only), hydrographics (`surface.liquid_fraction` in tenths), population (`settlements.population` powers of ten), government, law, tech (authored `society.*` facts, until a society suite publishes them).
- Bands are half-open (`[lo, below(hi)]`), so no two classes touch: `Atlas::overlaps` is empty for every scheme.
- 47 rules, kept inside the code sheet (`CodeSheet.rules`) so they tag nothing outside a reading: prepare flags, PBG counts, the T5 / Second Survey trade codes (planetary, population, economic) plus Sa, Lk, Tz from orbit and spin and the climate codes from surface temperature, authored zones (A, R), an amber hint from the codes, authored bases (N S W D M C K).
- About text carries the trademark notice; no publisher text, art or logo; no setting data.

## Checks (`cargo test -p sse-codes`, 11 tests)
- Pack loads beside the base atlas; stacked twice is a readable error; no overlaps.
- Solar System (fixture): Earth X867900-0, Venus X8C0000-0 (insidious, He), Mars X410000-0, Titan X3A0000-0, Jupiter XFA0000-0, Moon X200000-0 (Sa Va Ba), Mercury Ho Va Ba. Earth with authored society A867975-9, trade Ga Hi Pr, amber hint from government 7.
- Every digit answers why: label with base class, prepare-rule evidence (the oxygen flag cites `atmosphere.pp.o2` and pressure), defaulted facts listed, near misses present.
- PBG over the whole Solar System plus a belt: Earth 814, with the four giants listed; a belt main world reads X000000-0 with As.
- Authored size 3 on Earth: A367975-9, physics "8" kept beside it, disagreement flagged, Ga dropped.
- Round trips: 26 reference profiles (corners of every table) go code → pins → typical world → the same code; every symbol of every segment, one at a time, likewise; every Solar System world goes world → code → world → the same code; the population multiplier comes back (8e9 → 8).
- Pins in fact units (size 8 is radius 6,000 to 6,800 km); malformed lines refused; unknown symbols marked.
- New golden `tests/golden/traveller-codes.json` (pack hash and every Solar System body's UWP, PBG and trade codes).

## Limits
- Not yet in the kernel API, so nothing shows in the chart room yet (part 2 adds a `codes` op and a lens; the shell thread owns the UI).
- Field names are the classification fixture's (`atmosphere.pp.*`, `surface.liquid_fraction`, `settlements.population`); several axes are marked provisional until flows publish them.
- One edition of trade codes (T5 / Second Survey, what Travellermap publishes). Other editions become alternative rule groups.
- Starports, government, law and tech are authored facts; X3d's station templates can later feed the starport digit.
