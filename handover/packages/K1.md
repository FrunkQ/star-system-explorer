# K1: workspace, CI, canonical encoding, content hashes, pinned maths, hash harness

Status: done (18 Nov 2026).

## What was built
Cargo workspace (`sse-core`, `sse-cli`, `sse-wasm`), CI on three OSes plus wasm in Node and three browser engines, canonical CBOR, SHA-256 content hashes, pinned `libm` maths, and a cross-device hash harness page.

## Design sections implemented
H3 (numbers, hashing, serialisation), H12 experiment 1 (maths and encoding part; resolves and derives join it once they exist). Deviations: none. ADRs 0001 to 0003.

## Commands
```
cargo test --workspace
cargo run -p sse-cli --release -- harness          # must equal tests/golden/harness.json
scripts/build-harness.sh && node tests/harness/run-node.mjs
node tests/harness/run-browsers.mjs chromium firefox webkit
```

## Results
- 10,000 maths cases (20 unary and 9 binary pinned functions each, plus a Kepler solve), 10,000 random canonical-encoding cases (0 round-trip failures), 1,000 SHA-256 cases.
- Identical overall digest `d25a698f…8019d0` natively (Linux x86-64, debug and release), in Node 22 and in Chromium 157 (local run). CI adds macOS arm64, Windows x86-64, Firefox and WebKit.
- Unit tests: RFC 8949 integer vectors, float and NaN policy, key ordering, strict rejection of non-canonical input, serde round trip, SHA-256 known vectors.
