# U23: the interface reads constants from the master data sheet

Status: done 22 Nov 2026. MP22, the UI side: "no typed copies of constants", and the TS sheet reader the master data
thread left to the UI track.

## What it does

- `scripts/build-ui-reference.py` writes `packages/ui-contract/generated/reference-constants.json`, the master
  data sheet's constants (`packs/base-reference`, `provides.reference.constants`) unchanged as `{id: {v, unit, src}}`,
  with the pack's id and version. It holds only the constants: bundling the whole sheet (about 350 kB) into the
  page for a dozen numbers would cost every visitor. `--check` exits 1 when the copy is stale. The audit skips
  `generated/` directories, so the copy is not a typed copy.
- `packages/ui-contract/src/sheet.ts` is the one door: `constant(id)` gives the value in its SI unit, and
  `constantOf(id)` also gives its unit and source. An id the sheet lacks throws. `constantIds()` and `SHEET_PACK`
  are exported too.
- 21 typed copies in ui-contract now read the sheet, and their ledger lines are deleted (615 to 594):
  - make.ts: M_EARTH, M_SUN, R_EARTH_M, R_SUN_M, AU_M, L_SUN_W
  - orbits.ts: M_SUN, M_EARTH, AU_M
  - scene.ts: KM_PER_AU
  - light.ts: H, C, K, R_SUN_M, AU_M
  - route.ts: AU_M, R_EARTH_M
  - compare.ts: R_EARTH_KM, R_JUPITER_KM, R_SUN_KM
  - measure.ts: C_KM_S
  - calendar.ts: DAY
- Values that moved: M_sun is now the sheet's GM_sun / G (1.98841e30 kg, was 1.98847e30), and M_earth is 5.97217e24 kg (was 5.9722e24). Both changes are smaller than any displayed rounding.

## Checks

- `packages/ui-contract/test/sheet.test.ts`:
  - runs `build-ui-reference.py --check`, so CI's ui job fails on a stale copy;
  - every constant equals the pack's;
  - an unknown id throws;
  - make.ts's yardsticks are the sheet's.
- `ui:check`, `ui:test` and the full `ui:e2e` pass, as does the typed-copies audit.
