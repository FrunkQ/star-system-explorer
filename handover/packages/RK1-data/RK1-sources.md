# RK1 physics data sheet: cited source figures

Gathered 2026-11-23. Every value below was fetched from the source named next to it, in this session, using a text-extraction fetch tool. "read" means the number was taken from the fetched text of the document or page itself. "as summarised" means it came only from an abstract or summary. "computed" means simple arithmetic on read values, done by me (not printed in the source). "not found" means no primary or authoritative source was read for it within the fetch budget (about 60 fetches). No remembered figures are given.

**What "read" means here.** The fetch tool extracts the text and then quotes it through a small model, so "read" values are quoted extracts and not page-image checks. Many of the PDFs are OCR scans. Wherever the extract said the text was garbled, that is noted. Check the key numbers against the PDF before you publish.

**Hosted copies.** Some USAF reports were read from copies hosted on rocketprops.readthedocs.io or hydrogen-peroxide.us. These are copies of the original government reports, not secondary write-ups. The report is cited, with the copy's URL.
