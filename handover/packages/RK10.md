# RK10: one Bands table on the master data sheet (track RK)

This is Atomic Rockets plan section 12, item 1, and question 14, which Alex accepted on 23 Nov 2026. Every band that any part of SSE4 names now has one home: the `bands` table of `packs/base-reference`. It is built by `scripts/band_rows.py`.

## The table

There are three kinds of row:

| kind | rows | fields |
|---|---|---|
| `view` | `view-visible`, `view-infrared`, `view-ultraviolet`, `view-xray`, `view-radio`, `view-mag` | `view_id`, which is the view switch's own id, and `names` |
| `light` | `gamma`, `xray`, `uv`, `visible`, `near-ir`, `mid-ir`, `far-ir`, `mm`, `radio` | `from_m` and `to_m` (authored conventions), `view` (a view row id), `recipe` (the default recipe, where one exists), `names` |
| `channel` | `magnetic` | `view` and `names` |

A pack adds a band by adding a row.

## Checks

- **Kernel reader (`sse-reference`):** `bands` is now one of the sheet's tables. A light band must meet its neighbour with no gap. Every light or channel row must name a view row. The test is `bands_meet_end_to_end_and_name_a_view`.
- **Builder:** until the light thread reads the sheet, the builder checks that `packs/base-light`'s own band list agrees with the sheet.
- **Interface:** `scripts/build-ui-reference.py` writes the table into `ui-contract/generated/reference-constants.json`, and `ui-contract` exports it as `SHEET_BANDS` (type `SheetBand`). `sheet.test.ts` checks it.

## Found on the way

`ui-contract`'s own `BANDS` (light.ts) ends radio at 10 m. `packs/base-light` and the sheet end it at 10 km. The sheet takes base-light's value, because that is the copy the kernel's light table reads. The edge goes away once light.ts reads `SHEET_BANDS`.

## Repointing (other threads, each for its own strings)

- **Light thread (`sse-light`, `sse-sense`, `packs/base-light`):** read the light rows from the sheet and drop base-light's `bands` copy, then drop the builder's agreement check. RK11's `range_bands` are a setting's measure, not this table (RK11.md).
- **Renderer and chart room (`ui-contract` light.ts and view-controls.ts):**
  - `BANDS` and the hand-written `BAND_OF` map become reads of `SHEET_BANDS`: light row, then `view`, then that row's `view_id`.
  - `VIEW_BANDS` and `VIEW_BAND_WORDS` come from the view rows.
  - Recipes name bands by these ids, as they already do.
