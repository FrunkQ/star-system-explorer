# U1: shell, chart room tokens for both modes, chart grammar components

Status: done (18 Nov 2026), branch `claude/project-thread-adgixl`. Stops before U2, which needs P1.

## What was built
- `packages/skins/chart-room`: theme documents Chart room (light, default) and Night chart (dark; inherits and changes colours only), a token schema written for Orac (type, meaning, promoted), CSS custom properties, contrast checks.
- `packages/chart-grammar`: Svelte 5 parts drawn only with tokens: ChartGround, SurveyGrid (with A/B/C and 1/2/3 edge references), Ink (orbits, paths, belts, zone bands), HatchDefs and Hatch (hatch, cross, stipple, band), Mark (draws what symbology returns), Stamp (evidence and honesty stamps), Card and CardField (typed in place, Esc puts it back, "why?"), TimeRuler (slider with ticks, events, inked edits, keyboard), ToolButton, Segmented; pure ruler and scale maths with tests.
- `packages/views/{system-chart,body-card,time-ruler}`: the first three view modules, each with a parameter schema.
- `packages/shell`: the GM app. A fixed chart-room layout whose areas are filled from `documents/workspace.gm.json`; fixture scene `kestrel.scene.json` (labelled "Fixture data"); stub symbology. Header with Edit/View and Chart room/Night chart, tool rail, card pinned top right, time ruler, a status line (seat, kernel version, measured tier, state hash). Phone layout below 760 px: chart, then the card, ruler fixed at the bottom.

## Design sections implemented
H8.5 (chart room and night chart, paper ground, ink lines, survey grid, serif italic place names, monospaced values, one accent for selection and authored, hatching for unsurveyed, stamps, card pinned, values typed where shown, time ruler always present, why one tap away, no modal wizards, keyboard, phone layout), H8.4 (tokens only; symbology kept separate per H8.4A), H8.9 (schemas for theme tokens and every view's parameters).

## Results
- svelte-check: 0 errors, 0 warnings (warnings fail the check; Svelte's accessibility rules included).
- Contrast (WCAG): text tokens 5.1 to 14.7 : 1, lines and focus 3.05 to 9.5 : 1, both modes (`SSE_PRINT=1 node --test packages/skins/chart-room/test/themes.test.ts` prints the table).
- Keyboard only, Chromium: Tab reaches Tarn in 8 presses, Enter selects, Tab reaches Mass in 10 more, typing and Enter inks the edit; ruler Arrow and Page keys step 1 % and 10 %; E, V, N, T, C, [, ], ? and Esc work; view mode has no inputs.
- Phone (390 x 844): no sideways scroll in either mode; ruler visible.
- Screenshots at 1440 x 900 and 390 x 844 in both modes: `handover/packages/U1-screens/`. "Matches the Chart room board in spirit" is Alex's call.
- Firefox runs in CI (`ui` job); WebKit is not run yet (Tab focus differs on WebKit; worth adding with U2).

## Known limits
- Fixture scene, not physics; "why?" says so until U2 and P1.
- Tool rail has only Select and keyboard help; tools arrive with the packages that use them (U2 add body and drag, U3 flows), chosen by lenses in U9.
- No lens switcher yet (U9); honesty stamps show from scene data.
- Units with symbols outside IBM Plex Mono (for example ⊕) fall back to a system font in inputs.
- Shell bundle 2.5 MB including the 1.2 MB kernel wasm and fonts; no size work yet (X1).
