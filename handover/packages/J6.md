# J6 part 1: programs (state machines that drive a program seat)

Status: part 1 done (19 Nov 2026). Kernel track. Design: `handover/design/SSE4-record-logic-programs-design.md`, section 6 and section 10 row J6.

## What was built
**`sse_trigger::programs`.** Packs declare programs under `provides.other.programs`: `{programs: [...], limit?}` (the top pack's limit wins; default 16 running programs).
- `ProgramDoc {id, label, params, start, states, budget {max_steps}, explain}`.
- A state is `{id, pick?, act?, transitions}`:
  - `pick {where, by, order}`: among the subjects the program has **sensed**, those for which the K8 condition `where` holds, best by the number `by` (`max` or `min`). Ties go to the first in address order.
  - `act {kind, payload}`: the intent it sends. In the payload, `{self}`, `{pick}` and `{param.<name>}` are filled in.
  - `transitions [{when, to}]`: K8 conditions on the program's own object, plus `param.<name>` and `pick.found`.
- **Refused at load:** an unknown start state, a transition to an unknown state, `{pick}` without a pick, an unknown param, a bad id, an unknown key, duplicates, `max_steps` 0, and (in the kernel) an `act` kind that no pack declares as an intent.
- The record holds the running state: `programs.attached {program, seat, state}`, `programs.state {program, state, from}` and `programs.detached`. `running(record, at_s)` folds them, so a run replays.

**One tick (`programs_step {at_s}`)**, for every running program in address order:
1. **Skip** a program whose object is retired, whose template no longer lists it, or whose seat or pack is gone (reported, never an error).
2. **Sense** through the program seat's audience: the kernel builds that audience's scene and keeps only exact values shown to it. A drone acts on what its operators have been shown, never on the GM's truth.
3. **Think:** follow the first transition that holds, up to `max_steps` moves (each a `programs.state` event).
4. **Act:** send the state's intent through `send_intent` with the program seat, so the J5 checks apply (may_send, scope, validity, never_auto). If the state picks and nothing sensed fits, it waits.
5. Then one `rules_step` at the same time, so `on_intent` rules carry out what was sent.

**Kernel ops** (GM machine only): `programs {at_s?}`, `attach_program {address, program, seat, at_s}` (the object's template must list the program (J7 `may_run`), the seat must be a program seat for it, one program per object, the limit holds), `detach_program`, `programs_step`.

**J4 addition.** An `on_intent` rule's `set_kept` value written as `"{intent.<field>}"` takes that field of the intent that fired it (any JSON type), for example `drone.at = {intent.to}`.

**Fixture** `tests/fixtures/packs/rpg-programs.json` is a self-contained pack: data views (`ore.*` shown once scanned), kept `drone.at` and `drone.cargo_t`, the `drone` template, the intents `go`, `mine` and `unload`, the rules that carry them out, and the program `miner` (survey, mine, return, unload) with limit 2.

## Checks
- Kernel `programs_through_the_api`:
  - **Honest sensing.** With nothing scanned for the drone's operators, it waits at the depot for 12 ticks, though the GM knows of a 0.9-grade body. Once the GM scans the 0.6-grade body for `drone-ops`, the drone picks that one, not the richer unseen body.
  - **The cycle.** survey, mine ×4 (25 t a shift to a 100 t hold), return, unload, survey again, every intent applied through the record by its rules.
  - **Replay.** The same steps on a fresh kernel give the same record head, so a look-ahead branch equals the committed run.
  - **Limits.** A body (no template) is refused; a second drone attaches; a third is refused with `program_limit`; `programs` lists two running.
- `programs::tests::load_refusals_and_picks`: every load refusal by name; picks read only sensed facts and tie-break in order; the payload is filled.
- Contract: 11 new cases; line 1 lists the four ops. TypeScript types regenerated.

Golden changes (on purpose): `contract.jsonl` line 1 and the new cases at its end. No engine golden changed.
