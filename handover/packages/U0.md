# U0: one client API; every edit an intent (rule for all U packages)

Status: done (18 Nov 2026), branch `claude/project-thread-adgixl`.

## What was built
- `packages/ui-contract`: view contract and parameter schemas (H8.1, H8.9), screen documents with validation (H8.3), intents, seats and the approval rule (H8.7), and `Session`, the one door to the kernel for GM and player apps alike (H8.8). `host-browser.ts` starts a kernel worker and opens a session.
- `tests/ui/boundary.test.ts`: the lint that proves the shell and views import only the client API (and that it catches the private paths it should).
- ADR 0005 records the choices and the interim parts.

## Design sections implemented
H8.1, H8.3, H8.7 (seats, audiences, may_send, auto_approve; no seat UI yet, sealed seats are V10), H8.8, H8.9 (schemas with meanings and promoted flags; the Orac side comes later).

## Commands
```
scripts/build-wasm.sh            # once, or after kernel changes
npm run ui:test                  # node tests: intents, documents, themes, grammar, boundary
node tests/ui/shell.e2e.mjs      # browser: GM edit through the card equals the player-seat event
```

## Results
- Boundary lint: 0 breaches across the shell, views, chart grammar and skin sources (36 files); the checker flags all 6 planted private paths and passes 5 allowed imports.
- Same event: the GM seat and a player seat with `auto_approve` for `set_value` over `u:kestrel/sys:1` return identical `{event_id, state_hash, affected}` in Node (`packages/ui-contract/test/intents.test.ts`), and the edit typed into the shell's card in Chromium inks event `5d460c19...` which equals the Node player-seat event (`tests/ui/shell.e2e.mjs`).
- A player intent outside its scope waits (`pending`), leaves the state hash and history unchanged; a seat without `may_send` and a malformed intent are refused.

## Golden hashes
None added or changed.

## Known limits
- Pending intents wait in the local session; carrying them to the GM and approving is V5.
- Authored events carry publisher `gm/edit/1` whoever asked (kernel). Recording which seat asked belongs with V5.
- Kernel has no read of authored values, so cards show what the intent set (see ADR 0005).
