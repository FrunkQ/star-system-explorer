# K8: rules, classification, sifters, significance

Status: done (18 Nov 2026). Track "kernel resolve and rules", branch `claude/project-thread-dzkz4p`.

## What was built
New crate `sse-sift`: a declarative predicate language over a subject's facts (and its parent's), rules that put tags on subjects with hysteresis, the generic region-classification machinery of the classification design (axes, classes with cores and fringes, schemes, base and modifier, sticky labels, working with near misses), sifters over facts and chronicle events with evidence and a measured significance score, and loading all of these from packs.

## Design sections implemented
H6.6; classification design sections 3 to 5 as machinery (C1 brings the real axes, atlas and SSE 3 fingerprints). Choices the design left open:
- **Predicates** (`"if"` tag in JSON): `all`, `any`, `not`, `has`, `range` (with `margin`), `is`, `compare` (left op factor x right, with relative `margin`), `near` (relative tolerance), `tag`, `within` (a time fact between now + from and now + to). `parent.<field>` reads the parent's facts. Every evaluation returns the facts it read, sorted, as evidence.
- **Hysteresis**: a held tag stays while its `stay` predicate holds; by default `stay` is `when` read with its margins widened. Rules run in pack order and see tags already decided, so `garden` can build on `habitable`. `RuleSet::track` turns a time series (an ageing run) into dated tag changes with evidence.
- **Classification**: fit = lowest per-axis fit (1 in the core, linear fade across the fringe on the axis's scale, log axes in log10); a class inherits its ancestors' bounds; the base label is the deepest eligible class, then highest fit, then smallest normalised core volume, then id; modifiers stack at their threshold (default 0.6, as SSE 3). Stickiness: the held label is kept while it still fits within the atlas margin (default 0.1) and the challenger does not beat it by the margin. The label carries runners-up with each class's limiting axis and the signed change that would reach its core.
- **Significance**: four components in [0, 1], score is their mean: persistence (log years, saturating at 10 Gyr), reach (log addresses, saturating at 10,000), irreversibility (1 - declared reversibility), rarity (-log10 p, saturating at 1 in 10,000). Rarity p is the probability of the sifter's criteria under the subject's parent cloud (via `sse_resolve::query::criterion_probability`), so "unusual" is measured; with no cloud it is reported as not measured, not guessed.
- **Evidence**: each hit lists address, field, value and the chronicle event that last set that fact; a tag in a pattern is expanded into the facts its rule read; event sifters cite the matching events. Hits are ordered by score, then sifter id, then address.
- **Packs**: `provides.other.rules`, `.axes` (as `[id, axis]` pairs), `.classes`, `.sifters`, read through JSON so integers in a pack read as numbers. An id may be defined once across the stack (second definition is a readable error, never a silent override).
- Small change to K7's crate: `query::criterion_probability` and `query::value_matches` are now public (for rarity).

## Results
- Acceptance, tags with hysteresis: temperatures 300, 309, 311, 309.5, 313, 314.9, 316, 312, 309 K against a 273 to 310 K rule with a 5 K margin give exactly three changes (gained at t0, lost at 316 K, regained at 309 K); with the margin removed the same series changes at least five times. The dependent `garden` tag follows; the loss carries the 316 K reading as evidence.
- Acceptance, sifter hits carry evidence: on a campaign built from K7's patch fixture plus authored edits, the Roche sifter's hit names the moon's `orbit_m` with the id of the authored event that set it and the parent's `roche_m`; the metal-rich sifter's rarity is P(metallicity >= 0.2) = 0.1534 under the patch's truncated normal; the observe-grant sifter cites its event. Sifting appends nothing.
- Classification: deepest fit with modifier; near miss reports the ocean axis needing +0.3; unclassified lists nearest; a world warming 300 to 330 K keeps "temperate" at 312 K and 312.5 K by stickiness and changes label once, dated; malformed atlas (fringe inside core) rejected.
- Duplicate rule across two packs: "test.rival: rule habitable.v1 is already defined by test.sift-rules".

## Cost classes and edges
`sse_sift::ops()`: rules and classification trivial; sift light, linear in subjects x sifters in the scope (weak devices sift the open system; the GM machine sifts the campaign).

## Known limits
- Not yet in the kernel API (`sift`), see START-HERE.
- Sifters read current facts and events; patterns over sequences of events ("two impacts within 10 Myr") and naming epochs after the fact are left for U8/T2 to drive; the event pattern is the hook.
- Tag-change and label-change *events* are returned as data (`TagChange`, `Atlas::track`); writing them to the chronicle belongs to whoever runs the ageing (T2) so their causes can point at the evolve events.
